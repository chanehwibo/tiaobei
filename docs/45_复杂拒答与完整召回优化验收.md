## 2. 实现与兼容性

库、`MemoryService.search`、HTTP和复杂评测入口默认均为`focused_evidence_v2`。
实现位于`src/os_agent_memory/focused_evidence.py`及`memory_store.py`；
参数和响应解释见[API文档](13_API文档.md)。

- 对明确问句、指令及前置条件请求聚焦所问内容，保留必要主体，归一中文数量表达。
  不把设备编号或版本当数量改写。
- 有显式`required_terms`时按调用方约束过滤；未提供或为空时，在无歧义的请求中保留
  格式化设备/版本字面身份。明确排除的设备和叙述中的邻机不作目标；
  多目标歧义请求拒答。此能力不是任意实体识别或指代消解。
- 主种子必须达到`min_score=0.265`，再从相同精确主题的章节中选择互补证据，
  最多返回`top_k`条。只用实际返回且授权可见的标题/正文检查支持，
  不借用其他租户、已删除、未返回文档、标签、source_id或相关ID。
- 词面覆盖仍为固定0.5；属性问题增加正文片段支持检查，减少仅标题或无关句子的误支持。
  同主题章节关联和片段检查是透明启发式，不是语义蕴含、否定推理或通用多跳推理。
- 普通关键词查找保持原候选排序和分数，标记`evidence.origin=ranked_lookup`、
  `coverage=null`；关键词命中不宣称回答已被验证。
- 补全章节的顶层`score`表示包含种子贡献的证据束相关度，不是独立文档相似度或正确概率。
  `evidence`保留种子ID及文档、片段、直接分数；片段评分复用查询向量。
- 作用域、状态、有效期、重启、更新和遗忘过滤保持；不增加原始问句或答案缓存。
  旧`similarity`与`content_coverage_v1`仍可显式选择，后者只作历史实验。

阈值沿用旧v3开发集校准，没有用复杂集重新调阈值。旧v3校准诊断明确固定
`similarity`以保持其历史口径；它不是新策略或真实SDK已经校准的证明。

3. 对旧默认和旧实验分别检查：原本正确的请求仍正确，每个正例Recall不降低。
4. 对旧默认检查汇总Recall、Precision@3、MRR、nDCG、完整率、拒答率及干扰不退化。
5. 候选失败请求、异常和越域泄漏均为0，所有配置每轮P95均不超过500ms。

共七个机器检查项，三份比较结果均`optimization_gates_passed=true`。
1,440/576/576是每个对照策略的重复请求比较次数，不是独立样本数。
旧实验可能以空返回获得更低干扰比例，因此其逐请求成功与召回受保护，
但排序/干扰的汇总基准明确是旧业务默认`similarity`，没有声称所有指标优于旧实验。

三策略原始报告的总`all_targets_met=false`来自保留的旧对照失败；
须读取新策略逐配置的`all_targets_met`及上述比较器结论，不能涂改总标志。
新策略单独运行的`--require-targets`同时执行质量、完整性、安全和时延硬检查。
