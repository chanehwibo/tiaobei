# 研发记录

> 本文按时间保留每一阶段当时的测试数量和样例统计，它们是历史快照，不是当前结论。2026-09-05 当前固定版本为 61 项测试；现行评测与性能以 `artifacts/verification/final_verification.json` 为准。

## 2026-06-13

### 今日目标

建立项目基础骨架，完成首版可运行原型，开始沉淀赛题文档、研发记录和问题解决记录。

### 已完成

- 创建项目目录 `os-agent-memory-optimizer`。
- 建立 `src/`、`docs/`、`data/samples/`、`tests/`、`scripts/` 目录。
- 完成多源数据接入、清洗、质量评分和敏感信息过滤模块。
- 完成偏好记忆规则抽取模块。
- 完成知识记忆规则抽取模块。
- 完成内存版 MemoryStore，支持偏好版本化、知识检索、冲突标记和自然语言遗忘。
- 添加样例 JSONL 数据和基础单元测试。
- 编写赛题解读、技术路线、系统架构、评测方案和提交材料清单。

### 当前判断

首版原型的重点是跑通系统闭环，不追求最终算法指标。后续需要把规则基线替换或增强为“规则 + embedding + 置信度模型”的混合方案，并在银河麒麟桌面系统上做适配和延迟测试。

### 验证结果

- `python -m unittest discover -s tests`：3 个测试通过。
- `python -m os_agent_memory.cli demo --input .\data\samples\events.jsonl`：运行通过。
- demo 当前输出：3 条活跃偏好、11 个偏好版本记录、5 条活跃知识、1 条知识冲突。
- smoke 检索延迟约 1ms，远低于赛题 `<=500ms` 要求；该结果只是本机小样例 smoke test，不能代表正式数据集指标。
- `删除报销模板相关记忆` 命中并遗忘 1 条知识记忆。

### 下一步

1. 设计正式数据集字段和标注规范。
2. 增加 SQLite 或本地向量索引持久化。
3. 抽象 embedding provider，接入银河麒麟 embedding SDK。
4. 增加冲突融合策略，不只做冲突标记。
5. 设计一个真实办公场景 demo。
