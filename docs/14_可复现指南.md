## 5. 五项逐请求硬门槛与历史回归

```powershell
python -X utf8 -S scripts/evaluate_requests.py --size 10000 --require-frozen --output artifacts/runtime/requests.json
python -m os_agent_memory.cli evaluate --suite ".\data\eval\office_memory_eval.json" --top-k 3 --summary-only --output ".\artifacts\runtime\evaluation_v1.json"
python -m os_agent_memory.cli evaluate --suite ".\data\eval\office_memory_eval_v2.json" --split test --top-k 3 --summary-only --output ".\artifacts\runtime\evaluation_v2_test.json"
python scripts/evaluate_v3.py --require-quality --output artifacts/runtime/evaluation_v3.json
```

逐请求报告的五项数值、68/60/60/80/50分母、数据摘要和所有safety_checks必须通过；`--require-frozen`还核对固定provider、top_k、阈值及逐条结果与汇总的一致性，未满足返回非零。P95在10,000条记录上执行实际服务查询，不与规模基准的热p99混用。

`.gitattributes` 将冻结数据和原始证据标记为 `-text`，防止Git跨平台换行转换破坏原始SHA256。源码另提供只归一化CRLF的摘要，不能用归一化摘要替代原始证据摘要。

v3两项quality_targets继续作为历史检索回归，统一阈值来自dev；v1/v2旧标签含单条低证据输入，生命周期门控后有未达项。禁止放松门槛或改标签把它们标绿。延迟随机器负载变化，不复制历史值。

## 7. 环境与 SDK

```powershell

python -m os_agent_memory.cli kylin-sdk-check --module "实际SDK模块" --output ".\artifacts\runtime\sdk.json"
```

没有真实 SDK 时第二条应如实失败或 unavailable；不得构造 ready 报告。

在真实安装的V11客户机中执行：

```bash

```

输出目录必须新建；`/tmp`可能为符号链接，不能为运行测试削弱安全路径检查。对照 `kylin_vm.json` 的系统、根文件系统、虚拟化属性和file_hashes，不能把Windows报告改名为麒麟结果。
