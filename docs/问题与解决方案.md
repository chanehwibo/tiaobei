# 问题与解决方案

## 2026-06-13 PowerShell 创建目录参数兼容问题

### 现象

执行 `New-Item -LiteralPath` 创建目录时，当前 PowerShell 环境提示找不到 `LiteralPath` 参数。

### 影响

目录无法按原命令创建，但不影响项目本身。

### 解决方案

改用兼容性更好的 `New-Item -Path`，并逐个创建目标目录。

### 后续动作

项目脚本中尽量使用更通用的 PowerShell 参数写法，降低环境差异造成的执行失败。

## 2026-06-13 embedding SDK 尚未接入

### 现象

赛题要求调用银河麒麟国产桌面操作系统 embedding SDK，但当前研发环境未提供 SDK 文档和运行库。

### 影响

当前无法直接验证 SDK 调用效果和麒麟端侧真实性能。

### 临时方案

先实现 `EmbeddingProvider` 接口、`HashEmbedding` 端侧轻量 fallback、`CallableEmbeddingProvider` 通用 SDK 包装器和 `KylinEmbeddingProvider` 麒麟 SDK 适配器脚手架，保证检索链路、评测链路和接口边界可运行。

### 后续动作

获取官方 SDK 后优先通过 `KylinEmbeddingProvider` 指定模块名、工厂函数和方法名接入；若 SDK 只暴露简单向量函数，则通过 `CallableEmbeddingProvider` 包装，并在银河麒麟桌面系统上测试 `<=500ms` 延迟指标。

## 2026-06-13 当前规则抽取能力有限

### 现象

偏好抽取和知识抽取目前依赖关键词规则，只能覆盖可预期表达。

### 影响

面对自然语言变体、隐式偏好和复杂知识冲突时，准确率可能不足。

### 临时方案

把规则作为可解释基线，优先保证系统链路和评测闭环。

### 后续动作

引入更强的语义特征和置信度校准机制，建立标注数据集后用指标驱动迭代。

## 2026-06-13 slots dataclass 序列化问题

### 现象

demo 中直接使用 `result.__dict__` 输出检索结果，但项目里的数据结构启用了 `slots=True`，对象没有 `__dict__`。

### 影响

demo 在检索结果输出阶段抛出 `AttributeError`。

### 解决方案

改用标准库 `dataclasses.asdict()` 序列化 dataclass。

### 后续动作

后续所有结构化输出统一使用 `asdict()` 或显式 DTO，避免对象实现细节影响 CLI 和接口输出。

## 2026-06-13 unittest 默认发现范围问题

### 现象

执行 `python -m unittest` 时未发现 `tests/` 目录下的测试用例。

### 影响

测试命令返回未运行测试，不能作为有效验证。

### 解决方案

运行命令改为 `python -m unittest discover -s tests`。

### 后续动作

后续可以补充 `pytest` 配置；在无外部依赖阶段，先保留标准库 unittest discover 命令。

## 2026-06-13 遗忘指令匹配过窄

### 现象

`删除报销模板相关记忆` 被解析为单个关键词 `报销模板`，但样例知识标题是 `报销邮件模板`，没有连续包含 `报销模板`，导致遗忘数量为 0。

### 影响

自然语言精准遗忘能力不足，不能覆盖用户常见的概括式表达。

### 解决方案

在保留完整短语匹配的同时，增加领域原子词组合匹配。例如 `报销` 和 `模板` 同时出现在一条记忆中，也视为命中 `报销模板` 指令。

### 后续动作

正式版本需要把遗忘解析升级为意图识别 + 约束槽位解析，并给删除动作增加确认和审计记录。

## 2026-06-13 SQLite 文件句柄未关闭

### 现象

在 Windows 下运行 SQLite round-trip 测试时，`TemporaryDirectory` 清理阶段提示 `memory.sqlite` 正在被另一个进程使用。

### 影响

测试逻辑本身已经完成，但临时目录无法删除，导致单元测试失败。

### 原因

标准库 `sqlite3.Connection` 的上下文管理器负责提交或回滚事务，但不会在退出 `with sqlite3.connect(...)` 时自动关闭连接。

### 解决方案

使用 `contextlib.closing(sqlite3.connect(...))` 包装连接，确保 `save()` 和 `load()` 结束后释放文件句柄。

### 后续动作

后续新增 SQLite 或文件型存储时，统一显式关闭连接和文件句柄，并在 Windows 环境下验证临时文件清理。
