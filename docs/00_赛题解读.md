# 00 赛题解读

## 赛题定位

本题要求面向麒麟操作系统 OS Agent 的记忆模块，设计并实现“多源融合偏好记忆 + 知识记忆”的优化方案。重点不是做一个普通聊天助手，而是做可部署、可评测、可复用、可解释的 Agent Memory System。

## 核心问题

1. 工具调用结果结构化不足，导致偏好提取和知识沉淀质量不稳定。
2. 用户行为、手动配置、跨场景数据存在不一致，影响偏好动态更新。
3. 新旧知识冲突发现滞后，知识融合效率低。
4. 关联检索准确率和端侧响应延迟需要同时满足。
5. 敏感信息识别、过滤和自然语言遗忘必须纳入系统能力。

## 评审关注点

- 技术创新性：偏好提取、冲突处理、关联检索是否有机制设计。
- 方案可行性：是否能落地到端侧部署，是否有轻量化论证。
- 性能指标：偏好准确率、检索召回率、检索延迟、冲突处理正确率。
- 实用性：是否能直接解决 OS Agent 的真实业务痛点。
- 文档规范性：架构、算法、部署、测试是否完整。

## 建议作品形态

构建一个可演示的记忆中台原型，包含：

- 多源事件接入和清洗管线。
- 偏好记忆抽取、置信度、版本管理、跨场景复用。
- 知识记忆结构化入库、向量检索、冲突标记和融合。
- 敏感信息脱敏和精准遗忘。
- 标准化评测脚本和可视化演示材料。
