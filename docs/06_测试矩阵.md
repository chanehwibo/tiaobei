# 06 测试矩阵

更新时间：2026-09-04

## 自动化分层

| 层级 | 覆盖内容 | 主要证据 |
| --- | --- | --- |
| 单元测试 | 输入规范化、脱敏、偏好权重、知识冲突、索引、生命周期、指标公式 | `tests/test_memory_pipeline.py` |
| 服务集成 | ingest/preferences/search/conflicts/forget/stats 与 SQLite 往返 | `tests/test_memory_pipeline.py` |
| HTTP 端到端 | 仪表盘、JSON API、两阶段遗忘、错误请求 | `tests/test_web_server.py` |
| 性能回归 | 规模参数校验、报告字段、JSON/Markdown 归档 | `tests/test_benchmark.py` |
| 安全对抗 | 跨租户、提示注入、失败工具、硬删除、嵌套凭证 | `tests/test_security_adversarial.py` |

## 关键风险与防回归用例

| 风险 | 预期安全性质 | 测试 |
| --- | --- | --- |
| 相同用户 ID 跨租户串读/误删 | 检索和遗忘均限定 tenant+user | `test_same_user_identifier_cannot_cross_tenant_search_or_forget` |
| 外部文档提示注入形成长期记忆 | 标记风险、降权且不抽取 | `test_prompt_injection_is_neither_preference_nor_knowledge` |
| 失败工具被学习成首选 | failed/cancelled 证据不得入选 | `test_failed_tool_cannot_override_successful_user_selected_tool` |
| 硬删除后正文或向量残留 | SQLite 重载后目标 ID 不存在 | `test_hard_delete_has_no_orphan_after_database_reload` |
| 嵌套元数据泄露凭证 | 入库前递归脱敏 | `test_nested_credentials_are_redacted_before_any_extraction` |
| 多报偏好和未授权误删不扣分 | 假阳性、误删进入指标 | `test_metrics_penalize_extra_preferences_and_unapproved_deletions` |
| 未决冲突参与普通回答 | 默认检索不可见 | `test_pending_conflicts_are_hidden_from_normal_search` |

## 运行方式

```powershell
$env:PYTHONPATH="$PWD\src"
python -m unittest discover -s tests -v
```

自动化通过只能证明仓库内可复现行为；真实银河麒麟系统、真实 SDK、第三方盲测和真实用户案例仍需单独取得外部证据。
