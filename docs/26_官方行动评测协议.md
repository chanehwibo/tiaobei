# 官方行动评测对齐与证据边界

出题方方案要求一个样本一个容器、5个会话约50轮、会话间清空短期上下文而保留长期记忆。记忆事实以 object_id.attribute_id 为原子槽位；类似对象不是同一对象的冲突。最终评估文件、记忆、对话和工具轨迹，并由独立模型做槽位后验判断。

## 已实现的本地框架

`action_evaluation.py` 提供事实账本、50轮调度、会话上下文重置、独立控制器 oracle、实际文件后验检查、持久记忆终态及噪声/风险检查。15个行动文件使用不同路径保存，避免只检查最后一次覆盖结果。文件缺失、旧值、相似对象串扰、越界路径都会失败。空泛的“已完成”回答没有分数。

运行诊断（workspace 必须不存在或为空，报告必须位于 workspace 外）：

```powershell
python -S scripts/evaluate_actions.py --workspace C:/Users/CanhuiBao/TiaobeiLab/runs/action-new --output artifacts/runtime/action-new.json
```

默认 FixtureAdapter 仅解析固定句式并调用真实 Markdown 存储、写真实文件，用于验证评测器是否正常。15/15通过只证明框架自检，不是自然语言泛化成绩、KylinBot成绩、50个独立测试请求或官方准确率。公开合成题不是盲测。

## 真实适配入口

DockerSample 仅应在独立 V11 客户机内部使用，不要求安装宿主 Docker Desktop。镜像必须预先审查并以本地 sha256 ID 固定；禁止自动拉取。每样本一个容器贯穿所有会话，调用 run_sample 的 adapter_factory=container.adapter_factory；容器外部用上下文管理器确保关闭。用户须自行提供镜像内适配程序。

容器无网络、根文件系统只读、非root用户、去除 capabilities、禁止提权、限制内存/CPU/进程；唯一挂载是该样本空 workspace，不挂载标签、仓库、控制器目录、主目录、socket 或凭证。每轮 exec 独立进程，输入 JSON 只有 session、turn_id、reset_context、当前会话 history 和 message；输出 JSON 含回答与工具轨迹。适配器不得额外保存模型短期历史。关闭只移除本次生成的随机容器，不执行全局 prune。

目前容器启动参数仅做契约测试，尚未在真实容器运行。默认记忆判分读取合成替身的 JSON 槽位正文，不支持把任意自然语言正文自动当作正确值；真实 Agent 需接入独立 LLM Judge 并保留模型版本、逐槽判断与工具审计。报告中的 independent_llm_judge.executed=false 和 official_accuracy_verified=false 不得手工改为 true。

## 正式数据还需要什么

自然语言 persona 模拟器、至少50个独立请求的各项指标集、不同对象/属性分布、带旧值与新值的隐藏 trace、独立保管的标签、真实文件工具轨迹、真实 V11/容器/模型版本和人工抽检。不得给 Agent 提供 oracle，不得用重复50次同一道题补齐样本数。
