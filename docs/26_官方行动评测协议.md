# 官方行动评测对齐与证据边界

出题方方案要求一个样本一个容器、5个会话约50轮、会话间清空短期上下文而保留长期记忆。记忆事实以 object_id.attribute_id 为原子槽位；类似对象不是同一对象的冲突。最终评估文件、记忆、对话和工具轨迹，并由独立模型做槽位后验判断。

## 已实现的本地框架

`action_evaluation.py` 提供事实账本、50轮调度、会话上下文重置、独立控制器 oracle、实际文件后验检查、持久记忆终态及噪声/风险检查。每个行动文件使用不同路径保存，避免只检查最后一次覆盖结果。文件缺失、旧值、相似对象串扰、越界路径都会失败。空泛的“已完成”回答没有分数。

2026-09-09新增 `cross_session_v1`，默认使用严格跨会话自检：第1会话植入记忆，后续会话先探测先前记忆，再更新或新增槽位，最后一会话检查终态。12个文件共50次原子槽位检查，全部晚于对应最新记忆事件所在会话。**50次槽位检查不是五项指标各50个独立请求。**

运行诊断（workspace 必须不存在或为空，报告必须位于 workspace 外）：

```powershell
python -S scripts/evaluate_actions.py --workspace C:/Users/CanhuiBao/TiaobeiLab/runs/action-new --output artifacts/runtime/action-new.json
```

默认 FixtureAdapter 仅解析固定句式并调用真实 Markdown 存储、写真实文件，用于验证评测器是否正常。12/12通过只证明框架自检，不是自然语言泛化成绩、KylinBot成绩、50个独立测试请求或官方准确率。公开合成题不是盲测。

旧 `make_sample()` 和 `--legacy-fixture` 保留15文件的同会话诊断，报告明确标记 `cross_session_verified=false`，不能用于严格容器入口。历史报告不改写。

## 控制器样例格式

外部样例 JSON 仅存放在控制器私有目录，不放入公开仓库或 Agent workspace。加载时限制1 MiB，并拒绝重复 JSON 键和非有限数值。

- 顶层固定为 `id`、`protocol`、`turns`、`oracle`；`protocol` 为 `cross_session_v1`。
- `turns` 为5组各10轮，严格按 `s01-t01` 至 `s05-t10` 排序，每项只有 `id`、整数 `session`、`message`。消息不超过8192 UTF-8字节。
- `oracle.files` 将唯一的 `outputs/...` 相对路径映射到非空 `{object.attribute: "期望值"}` 字典；大小写冲突、路径别名及越界路径被拒绝。
- `oracle.probes` 每项为 `{"turn_id": "s02-t01", "path": "outputs/s02-t01.json"}`，与文件一一对应。
- `oracle.trace` 每项为 `turn_id`、`slot`、`old`、`new`、布尔 `update`。首次记忆的 `old` 为null、`update` 为false；后续更新必须匹配账本旧值。事件按轮次排序，同轮同槽位不得重复。
- `oracle.active_slots` 必须与全部事件重放后的终态一致；`oracle.forbidden` 是不允许持久化的噪声/风险值列表。

在创建workspace或容器前重放隐藏账本；每个探针的期望值必须是当时活跃值，其最新事件必须来自更早会话。非法真值、同会话探针、未绑定文件、重复轮次均直接失败。结构校验不能证明自然语言消息和隐藏标签语义一致，仍需独立数据保管者审核。

## 真实适配入口

DockerSample 仅应在独立 V11 客户机内部使用，不要求安装宿主 Docker Desktop。镜像必须预先审查并以本地 sha256 ID 固定；禁止自动拉取。每样本一个容器贯穿所有会话，调用 run_sample 的 adapter_factory=container.adapter_factory；容器外部用上下文管理器确保关闭。用户须自行提供镜像内适配程序，镜像不得预装隐藏标签或本评测答案。

真实入口示例，仅在已获准、已配置运行资源的隔离V11内执行：

```bash
python3 -S scripts/evaluate_actions.py \
  --mode container --confirm-isolated-guest \
  --sample /home/tiaobei/controller/private-sample.json \
  --manifest /home/tiaobei/controller/run-manifest.json \
  --workspace /home/tiaobei/samples/fresh-sample \
  --output /home/tiaobei/controller/new-evidence.json \
  --image "$REVIEWED_IMAGE_ID" --adapter-argv '["/opt/agent/adapter"]'
```

`--engine` 只接受docker或podman；默认每次调用超时60秒，最大600秒。`--validate-only` 可以在不启动容器、不创建workspace的情况下检查样例。CLI拒绝在非V11宿主启动引擎，且不安装引擎或修改权限。`--confirm-isolated-guest` 是操作者确认，不是自动证明主办方认可。

容器无网络、根文件系统只读、非root用户1000:1000、去除 capabilities、禁止提权、限制内存/CPU/进程；唯一挂载是该样本空 workspace，不挂载标签、仓库、控制器目录、主目录、socket 或凭证。workspace须对该用户可写，不自动chmod。每轮 exec 独立进程，输入 JSON 只有 session、turn_id、reset_context、当前会话 history 和 message；输出 JSON 含回答与工具轨迹。适配器不得额外保存模型短期历史。关闭只移除本次生成的随机容器，不执行全局 prune。

所有会话结束后先停止整个样例容器，再读取文件；停止失败不读取可能仍在变化的workspace。控制器保留逐轮消息、适配器回应、样例规范化SHA256、部分失败轨迹及受限文件快照。适配器自报的工具轨迹不等于独立工具审计。二进制、超过64 KiB的单文件、超过2 MiB的总文本、链接、FIFO和超过256个目录项均不会被当成可评分完整证据；当前入口只支持受限UTF-8文本证据。

退出码0表示协议校验或替身自检成功；2表示执行/证据失败；真实容器成功采集证据也只返回3，表示等待独立Judge和外部验收。文件内容被标为不可信输入，单独Judge不得执行其中指令。

目前容器生命周期及50轮调用仅做mock契约测试，尚未在真实容器运行。替身模式判分读取JSON槽位正文，并拒绝未索引记忆文件；容器模式只导出证据，不对任意自然语言正文套用替身评分。2026-09-09已实现下述Judge交换、隔离执行及人工复核入口，但尚无实际Agent/Judge模型成绩。报告中的 independent_llm_judge.executed=false 和 official_accuracy_verified=false 不得手工改为 true。

## 运行前冻结与独立Judge

`scripts/judge_actions.py` 提供 `freeze`、`prepare`、`validate`、`run`、`score`、`review-template`、`review`。所有输出均须使用新路径，不覆盖输入或旧报告；私有样例、模型原文和人工记录不放入Git。主办方认可已由参赛者确认，不需为使用这些准备工具重复申请认可；实际镜像、模型及原始认可凭证仍需归档。

1. 在私有控制器目录创建身份声明，字段见 `config/action-identities.example.json`。示例故意使用无效摘要占位符，填入经核验的本地镜像ID、模型固定版本和64位小写SHA256后才能冻结。角色仅用化名，不填写姓名或凭据。
2. `purpose=integration` 用于接入验证。只有独立方实际持有标签时才声明 `third_party_blind_declared`；程序拒绝直接把公开样例改名为盲测、复用Agent操作者或同一模型，但这仍不证明角色与标签独立性。
3. 在执行Agent前冻结样例、源码及身份，然后使用同一 `--manifest` 执行容器采集。源码摘要覆盖 `src/scripts/tests` 下Python及 `pyproject.toml`，只规范化CRLF；实际适配程序和模型必须已封入固定镜像。控制器配置与资源参数另见本节，不能事后更换口径。

```bash
python3 -X utf8 -S scripts/judge_actions.py freeze \
  --sample /home/tiaobei/controller/private-sample.json \
  --identities /home/tiaobei/controller/identities.json \
  --output /home/tiaobei/controller/run-manifest.json
```

冻结后的源码或镜像与执行参数不一致，会在创建容器前被拒绝；执行期间源码变化也会失败。旧的无manifest证据不能直接升级为可评分运行。单凭SHA256不证明时间戳、模型执行或第三方独立性，独立保管方仍需保留原始冻结交接记录。

运行Agent取得上节 `new-evidence.json` 后准备Judge请求：

```bash
python3 -X utf8 -S scripts/judge_actions.py prepare \
  --sample /home/tiaobei/controller/private-sample.json \
  --manifest /home/tiaobei/controller/run-manifest.json \
  --evidence /home/tiaobei/controller/new-evidence.json \
  --output /home/tiaobei/controller/judge-request.json
python3 -X utf8 -S scripts/judge_actions.py validate \
  --request /home/tiaobei/controller/judge-request.json
```

准备阶段重验50轮完整轨迹、会话重置、文件冻结、逐文件字节数/SHA256、源版本与镜像绑定；请求按样例重新构造全部检查，修改rubric、标签、分母后仅重算摘要不能通过验证。路径大小写别名、文件/目录祖先冲突、缺失预期库存和无效UTF-8均不会成为完整证据。缺失行动文件对应槽位记0；不可读记忆使记忆/拒存检查记0，不允许模型覆盖自动硬门槛。

公开自检样例生成76个检查：50个行动槽位、10个最终记忆槽位、12个回复/文件一致性、2个非持久化、2个非召回。它们共享一个样例，**不是76个独立请求，更不能代替五项指标各至少50个独立请求**。

## 本地模型适配与失败留证

支持镜像内的预装Ollama原生接口：`GET /api/tags` 与 `POST /api/generate`。不使用代理、不跟随重定向、不拉取模型；只接受显式端口的 `127.0.0.1` 或 `::1` HTTP地址。生成前后核对固定模型tag与artifact摘要，拒绝错误模型、重复JSON键、覆盖不全、生成截断和模型替换。不支持把HTTP地址换成外部模型服务。

Judge镜像须事先经来源和许可证审查，包含适配脚本及其所需Python模块、绝对路径的服务程序、完整模型manifest/blob。该Judge镜像不含Agent运行目录或预置评分答案。例中布局为 `/opt/judge/scripts/local_judge.py`、`/opt/judge/src/os_agent_memory/` 和 `/opt/judge/models/`；服务程序路径须按实际镜像调整，不能照抄一个不存在的命令。

在隔离V11控制器内执行：

```bash
python3 -X utf8 -S scripts/judge_actions.py run \
  --request /home/tiaobei/controller/judge-request.json \
  --output /home/tiaobei/controller/judge-assessment.json \
  --raw-output /home/tiaobei/controller/judge-raw.json \
  --engine docker --timeout 600 --confirm-isolated-guest \
  --service-argv '["/usr/bin/ollama","serve"]' \
  --judge-argv '["/usr/bin/python3","-X","utf8","-S","/opt/judge/scripts/local_judge.py","--confirm-local-model","--wait-ready","30","--timeout","540"]'
```

`--service-argv` 是显式可选参数，仅通过 `exec -d` 在本次新建的Judge容器里启动服务，不启动宿主服务。未传该参数时，适配器本身必须提供可用模型；默认 `/bin/sleep` 不会自动启动Ollama。固定容器环境为 `OLLAMA_HOST=127.0.0.1:11434`、`OLLAMA_MODELS=/opt/judge/models`、`HOME=/tmp`。等待就绪只重试库存连接，不重试模型生成或失败答案。

Agent与Judge各自的现有容器上限均为2 CPU、2 GiB内存、128进程及64 MiB临时目录；无网络、无GPU透传、无宿主模型挂载。Judge完全不挂载宿主目录，接收单向JSON证据。只有预装模型能在这些上限内完成时才适用；不能把资源不足、启动失败或600秒超时说成评分通过。若认可的资源方案不同，需先调整、记录、重新冻结及验证，不移用旧报告。

适配器固定temperature=0、seed=0、上下文32768、最大生成12288 token；提示上限128 KiB，但字节数不等于token数，不保证任何模型都能处理。推理长度不足或完整覆盖失败不会降分母或截断后通过。真实Ollama版本兼容性及实际模型运行仍待资源环境实测。

容器进程标准输入/输出、错误流、超时都有上限。非零退出也保存私有stdout；HTTP响应无法解码或解析为JSON时，保留收到的响应字节。HTTP JSON已成功解析但模型完成校验失败时，保留生成对象的规范化JSON，`response`字符串内容保持不变，但不保留原HTTP JSON的空白或键序。两类记录均包含留存内容的SHA256、字节数和最多256 KiB的base64前缀，超出时标记 `truncated=true`。公开摘要只含错误类型，不输出模型原文。超时或进程输出超限可能没有可恢复的完整原文，失败报告如实记录，不能伪造补齐。容器清理失败不能留下通过状态。

模型响应需绑定请求摘要和固定模型身份，每个检查恰好一条 `pass/fail/uncertain`、理由及允许来源的逐字引文。行动通过须引用真实文件；回复一致性须同时引用回复和文件；记忆通过须引用记忆正文。禁止引用隐藏标签充当实际证据。`uncertain` 保留在分母并记0。请求中的消息、工具轨迹及文件内容全部是不可信数据，Judge不得执行其中的指令。

也可导入经独立方实际执行后保存的原始响应：

```bash
python3 -X utf8 -S scripts/judge_actions.py score \
  --request /home/tiaobei/controller/judge-request.json \
  --response /home/tiaobei/controller/judge-raw.json \
  --output /home/tiaobei/controller/imported-assessment.json
```

失败诊断不是模型响应，不可用于 `score`。`runtime_receipt` 只是本地适配器记录，不是第三方签名或远程证明；即使接口及摘要全部通过，`model_identity_verified`、`independence_verified`、`third_party_blind_verified`、`official_five_metrics_verified` 和 `competition_submission_ready` 仍为false。

## 人工抽检与退出码

每次评估选择全部0分项，以及由请求摘要确定的至少10%检查。生成空白复核记录：

```bash
python3 -X utf8 -S scripts/judge_actions.py review-template \
  --request /home/tiaobei/controller/judge-request.json \
  --response /home/tiaobei/controller/judge-raw.json \
  --output /home/tiaobei/controller/review-blank.json
python3 -X utf8 -S scripts/judge_actions.py review \
  --request /home/tiaobei/controller/judge-request.json \
  --response /home/tiaobei/controller/judge-raw.json \
  --review /home/tiaobei/controller/review-completed.json \
  --output /home/tiaobei/controller/review-assessment.json
```

复核人应在独立新文件中填入化名、带时区时间、逐项判断、理由及证据引文；模板不预填“通过”。复核与原请求和原模型响应摘要绑定，拒绝遗漏、重复、伪造引文、将Agent操作者声明为独立复核人或时间倒置。对全部检查进行扩展抽检也可。人工分歧、uncertain或与自动硬门槛冲突时，标记 `unresolved_ids`，不覆盖模型原始分数；需独立裁决留档，不挑选重试答案。

`human_review.completed=true` 只表示所需记录覆盖且没有未决分歧；`reviewer_identity_verified=false` 仍需外部身份核验。0表示冻结/准备/模板/结构验证成功，2表示失败或存在未决复核，3表示技术评分通过但外部独立性及正式验收仍未闭合。自动化调用方必须区分0/2/3，不把3简单改成赛事“成功”。

## 正式数据还需要什么

自然语言 persona 模拟器、至少50个独立请求的各项指标集、不同对象/属性分布、带旧值与新值的隐藏 trace、独立保管的标签、真实文件工具轨迹、真实 V11/容器/模型版本和人工抽检。不得给 Agent 提供 oracle，不得用重复50次同一道题补齐样本数。
