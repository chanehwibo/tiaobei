## 环境

- 安装镜像：官方 V11 2603 x86_64 试用镜像，固定摘要见 `scripts/manage_lab.py`。
- 系统：`Kylin V11`，`VERSION_ID=v11`，内核 `6.6.0-63-generic`。
- Python 3.12.3，SQLite 3.42.0；FTS5、JSON1 可用。
- 根文件系统：`/dev/sda3` 的 OSTree 部署，ext4；不是 overlay、Live 或光盘根目录。
- 虚拟化：VMware；4 vCPU、6 GiB 配置内存（客户机识别 5.787 GiB）。
- 虚拟网卡、共享文件夹、剪贴板、USB 均关闭。代码通过只读 ISO 传入，报告通过专用虚拟串口导出。
- 没有在宿主安装或升级软件、修改 PATH、网络、注册表或分区。

## 命令与结果

在客户机解压后的项目目录运行，输出目录必须尚不存在：

