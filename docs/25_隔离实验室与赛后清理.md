# 隔离实验室与赛后撤除

实验室唯一根目录：C:/Users/CanhuiBao/TiaobeiLab。现有 VMware 仅作为运行器，不属于本项目卸载范围。

| 子目录 | 内容 | 对宿主的边界 |
| --- | --- | --- |
| python | 无系统包继承、无 pip 的专用 venv | 不改现有 Python、PATH、用户 site-packages |
| vm | 6GiB内存、4vCPU、80GB按需增长虚拟磁盘与VM配置 | 不是物理磁盘；网络/USB/共享目录/拖放/剪贴板禁用 |
| iso | 官网镜像及校验记录 | 不写入宿主启动盘 |
| cache、sdk-source、runs | 项目缓存、SDK参考源码、测试产物 | 不写宿主应用环境，不公开凭据/原始私人数据 |

准备：python scripts/manage_lab.py prepare --root C:/Users/CanhuiBao/TiaobeiLab。
状态：python scripts/manage_lab.py status --root C:/Users/CanhuiBao/TiaobeiLab。

仅使用现有 D:/ProgramFiles/vmware 中的磁盘工具创建专用 vm/system.vmdk；不升级 VMware、不改虚拟网络编辑器。VM启动会消耗CPU/内存，并可能产生 VMware 自身正常运行日志/最近使用记录，因此不承诺宿主零字节写入；不更改现有软件安装、依赖或全局配置。任何需要改全局网络、驱动、系统功能或重启的步骤先停止并请求确认。

## 赛后撤除（现在不执行）

1. 保存需要的报告，关闭专用虚拟机；不要停止其他虚拟机或卸载 VMware。
2. 执行 status，核对列出的所有文件与 inventory_sha256；任何未知顶层文件、符号链接/重解析点或VM锁会阻止自动处理。
3. 明确确认后才运行 retire --root <上述目录> --confirm <刚核对的摘要>。它只把实验室重命名为同级 TiaobeiLab-retired-<id>，可以恢复，不永久删除。
4. 若 VMware 界面曾手动添加该虚拟机，只从库中移除此专用条目；不要误选其他虚拟机。确认无需恢复后，由用户按明确目录删除退休文件夹以释放空间。

严禁使用卸载现有 Python/VMware、重置网络、删除用户目录等方式清理。镜像、VMDK及私有运行日志不进入 Git 仓库。
