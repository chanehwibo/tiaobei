# 源代码模块说明

| 模块 | 职责 | 关键边界 |
| --- | --- | --- |
| `schemas.py` | 事件、偏好、知识、状态、遗忘、审计数据模型 | 统一枚举与默认值 |
| `security.py` | 正文/嵌套元数据脱敏、记忆污染标记 | 原始敏感值不进入后续层 |
| `ingestion.py` | JSONL、规范化、校验、UTC、去重、错误隔离 | 单条坏数据不终止批次 |
| `preference.py` | 多维规则、证据权重、时间衰减、工具反馈 | 失败工具不入选 |
| `knowledge.py` | 可复用知识抽取、类型和标签 | 风险事件不抽取 |
| `lifecycle.py` | 短期 TTL、中期聚合、长期门控/过期/降级 | 决策带分数和原因 |
| `embeddings.py` | Hash 回退、Callable、Kylin SDK 适配、自检 | SDK 可替换且不回显密钥 |
| `memory_store.py` | 偏好版本、知识、冲突、混合检索、遗忘、索引 | tenant+user 强隔离 |
| `persistence.py` | SQLite v2 保存/加载、v1 迁移 | 保存向量、审计和决策 |
| `service.py` | 稳定应用服务接口、可选自动持久化 | 客户端不直接改内部字典 |
| `web_server.py` | localhost 仪表盘和 JSON API | 仅演示用途，1MB 请求上限 |
| `evaluation.py` | 分区评测、P/R/F1、MRR、nDCG、误删率 | 无答案和假阳性计分 |
| `benchmark.py` | 四档规模、冷/热延迟、资源和报告 | 环境与限制写入报告 |
| `compatibility.py` | OS/架构/Python/SQLite/资源/SDK 分层报告 | 本地就绪不等于赛题就绪 |
| `diagnostics.py` | 一键演示前阻断项和外部警告 | 端口/文件/FTS5 预检 |
| `cli.py` | demo、evaluate、serve、benchmark、doctor 等入口 | 只做编排，不承载核心算法 |

测试目录按核心、Web、性能、环境、诊断和安全对抗拆分；脚本目录保存确定性数据、PPT 和一键演示生成/编排逻辑。
