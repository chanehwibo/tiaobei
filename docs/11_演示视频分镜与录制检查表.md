## 操作与口径

```powershell
python -X utf8 -S scripts/evaluate_requests.py --size 10000 --require-frozen --output artifacts/runtime/video-requests.json
python -X utf8 -S -m unittest discover -s tests -v
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_demo.ps1 -SkipTests
```

仪表盘默认 `http://127.0.0.1:8765`。端口占用时以 `-Port 8766` 启动并同步字幕。
新增评测或服务运行会改变输出，录制前保存新报告，不覆盖封存证据。
预览与确认之间至少停留3秒，不剪掉授权步骤。查询结果应展示来源ID与状态，
不能只展示“通过”汇总。
