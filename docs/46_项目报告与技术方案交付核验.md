## 4. 证据绑定与结论边界

材料工具在 `docs/materials_20260911/`，不放入已测量的运行代码目录。
生成前重新校验149个执行文件的LF摘要、固定数据原始字节、Windows最终报告、
三份三策略矩阵及比较器、两组开发结果和真实SDK原始探针。
同次七项比较器结论重新计算，与封存结果完全一致。

- 冻结五项：68/60/60/80/50分母不变，四项质量100%，80查询P95为48.145ms。
- 复杂集：18场景、168个不同请求；原集72/72完整、24/24拒答，约束开/关均
  24/24完整、12/12拒答；1千/1万、0%/75%填充、各三轮分别计分。
- 开发集：20个请求及追加10个反例另列，不并入复杂集、不冒充盲测。
- 干扰与代价：原集39/123、约束集9/39干扰返回仍披露；原集新策略有证据检查开销，
  不声称零干扰、普遍加速或Agent最终答案正确。
- SDK：单探针13,390.615ms、768维，包含进程、会话和初始化；原生P95仍为空，
  状态为“待复测风险项”。初始化若在search/provider调用内发生，必须计入服务耗时。
- Windows公开合成结果不替代当前源码V11、真实Agent/Judge或授权真实案例验收。

本次复用并重算已封存性能证据，没有生成新时延成绩，也没有修改旧失败标志。
运行源码、数据、配置、`pyproject.toml`及`.gitattributes`均未改动。
