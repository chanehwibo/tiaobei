# 演示操作手册

第五轮口径：偏好≥85%、召回≥85%、冲突≥88%、检索P95≤500ms、敏感F1≥90%，每项至少50个不同请求。当前数字由 `docs/32_第五轮验收报告.md` 和 `round5/evidence_summary.json`统一提供，不能沿用旧测试数或v2满分。

更新时间：2026-09-07

本手册用于现场答辩、录屏和新电脑复现。所有命令都从项目根目录执行，不依赖创建者电脑的绝对路径。建议在资源管理器中进入 `os-agent-memory-optimizer` 文件夹后使用“在终端中打开”。

## 1. 演示能证明什么

演示可以证明当前提交的记忆闭环和公开合成回归可运行。V11客户机已实测，需展示其独立报告和源码摘要；Windows终端不能替代它。旧ABI单探针成功不代表原生完整集成，独立盲测、真实案例和赛事流程尚未通过。

成功判定：

- 预检输出 `ready_for_local_demo: true`，真实麒麟和 SDK 仍可作为非阻断 warning。
- `latest_requests.json`的五项指标、请求数、数据摘要和全部安全门槛通过。
- 自动化测试输出当前测试数和`OK`，与对应源码版本报告一致。
- 一键脚本输出 `Local demo verification finished.`。
- 启动界面时只能绑定 `127.0.0.1`，浏览器可访问 `http://127.0.0.1:8765`。

测试数量以当前终端和第五轮证据摘要为准；不能要求旧v2全部通过而放松持久化授权门槛。

## 2. 录屏前检查

在项目根目录打开 PowerShell：

```powershell
python --version
git status -sb
Test-Path ".\data\samples\events.jsonl"
Test-Path ".\data\eval\office_memory_eval_v2.json"
Test-Path ".\data\eval\request_regression_v1.json"
```

要求Python 3.10或更高版本，所有`Test-Path`返回`True`。录制画面中不得出现真实姓名、联系方式、报名表、浏览器账号、SDK密钥或本机私有文件。

首次使用在独立venv中安装项目，不修改宿主Python：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

不安装时，在当前 PowerShell 会话设置：

```powershell
$env:PYTHONPATH="$PWD\src"
```

## 3. 推荐的一键演示

### 3.1 只验证、不启动服务

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1" -NoServer
```

脚本依次执行：

1. Python、文件、目录、SQLite FTS5 和端口预检；
2. 合成样例的接入、偏好、检索和遗忘；
3. v2历史标签诊断，未达项如实保留；
4. 五项逐请求硬门槛，10,000条记录；
5. SQLite v2数据库构建；
6. 全部自动化测试。

运行产物写入 Git 忽略的 `artifacts/runtime/`。最后应看到：

```text
Ran <当前测试数> tests
OK
Local demo verification finished.
Dashboard was not started because -NoServer was supplied.
```

### 3.2 启动浏览器仪表盘

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1"
```

出现 `Dashboard: http://127.0.0.1:8765` 后，用浏览器访问该地址。展示完成后回到终端按 `Ctrl+C`。端口被占用时改用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1" -Port 8766
```

## 4. 分步演示流程

### 步骤一：环境预检

```powershell
$env:PYTHONPATH="$PWD\src"
python -m os_agent_memory.cli doctor --workspace . --input ".\data\samples\events.jsonl" --suite ".\data\eval\office_memory_eval_v2.json" --host 127.0.0.1 --port 8765
```

旁白：

> 预检把当前进程运行条件与赛事验收分开。Windows本机warning保留，V11客户机另有实测；SDK探针和官方验收也分别报告。

### 步骤二：样例闭环

```powershell
python -m os_agent_memory.cli demo --input ".\data\samples\events.jsonl"
```

样例输出包含活跃偏好、版本、知识和隔离冲突数量。以当前命令输出为准，不把演示样例数量当作评测分母。

旁白：

> 系统先校验并脱敏六类来源事件，再抽取带作用域和证据的偏好、知识。未决冲突不会进入普通回答；检索后以自然语言生成遗忘预览，再由确认令牌执行删除。

### 步骤三：冻结五项逐请求评测

```powershell
python -X utf8 -S scripts/evaluate_requests.py --size 10000 --require-frozen --output artifacts/runtime/latest_requests.json
```

数据集偏好68请求、知识60正例、冲突60组、性能80查询、敏感50请求。重点展示metrics、observation_counts、safety_checks、dataset.sha256及逐项失败明细。

旁白：

> 这里是开发者持有标签的公开合成冻结回归。当前五项内部目标通过，但不能据此声称独立盲测或真实Agent成绩通过。

检查报告：

```powershell
Test-Path ".\artifacts\runtime\latest_requests.json"
Get-Content -Encoding UTF8 ".\artifacts\runtime\latest_requests.json" | Select-Object -First 80
```

### 步骤四：SQLite v2 持久化

```powershell
python -m os_agent_memory.cli build-store --input ".\data\samples\events.jsonl" --output ".\artifacts\runtime\memory.sqlite"
Get-Item ".\artifacts\runtime\memory.sqlite" | Format-List FullName,Length,LastWriteTime
```

旁白：

> 记忆、版本、状态、作用域、向量和审计记录被保存到端侧 SQLite。运行文件不进入公开仓库，可随时从源码重建。

### 步骤五：自动化测试

```powershell
python -m unittest discover -s tests -v
```

旁白：

> 当前测试覆盖单元、SQLite迁移、服务集成、HTTP端到端、安全对抗、指标、性能报告、SDK诊断、隐私和打包。数量以本次完整输出为准。

### 步骤六：固定性能证据

```powershell
Get-Content -Encoding UTF8 ".\docs\32_第五轮验收报告.md"
```

报告分别引用Windows和V11的10,000条、80请求P95，均使用HashEmbedding。旁白需说明它不含HTTP或Agent推理，旧ABI单探针也不是原生P95。原始报告路径见同页证据区块。

完整验收通常需数分钟，应在录制前运行：

```powershell
python .\scripts\verify_release.py --artifact-dir artifacts/runtime/release --sizes 100,1000,5000,10000 --rounds 30
```

## 5. 仪表盘演示顺序

1. “概览”：指出记忆数量、作用域和本地数据库。
2. “接入”：粘贴视频脚本中的虚构事件，展示正文与嵌套元数据脱敏。
3. “偏好”：展示维度、版本、置信度、场景和证据来源。
4. “知识查询”：指定 tenant/user，展示词法分、语义分和拒答机制。
5. “冲突”：展示 `conflict_pending` 隔离，再选择接受新版本或证据合并。
6. “遗忘”：先 preview，核对范围后再 confirm；强调令牌过期、作用域和审计回执。

不要在录屏中输入真实个人信息。建议使用 `docs/11_演示视频分镜与录制检查表.md` 中明确标为虚构的夹具。

## 6. 常见故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: os_agent_memory` | 未安装且未设置模块路径 | 执行 `python -m pip install -e .`，或 `$env:PYTHONPATH="$PWD\src"` |
| `Ran 0 tests` | 不在项目根目录或命令不完整 | 回到包含 `tests` 的根目录，执行 `python -m unittest discover -s tests -v` |
| 端口占用 | 已有服务使用 8765 | 一键脚本追加 `-Port 8766` |
| PowerShell 禁止脚本 | 执行策略限制 | 保留命令中的 `-ExecutionPolicy Bypass`，只对该进程生效 |
| SQLite 被占用 | 文件被查看器打开 | 关闭查看器，换一个 `-StorePath` 或删除运行时副本后重试 |
| 中文乱码 | 终端编码不一致 | 执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` |
| 真实 SDK 检查失败 | 未安装、模块名或接口配置错误 | 保留为外部阻断；按 `docs/07_银河麒麟适配说明.md` 在授权环境配置 |
| 全量验收返回 2 | 某个本地硬检查失败 | 打开指定输出目录的`final_verification.json`定位`checks`和明细，保留失败后完整重跑 |

## 7. 录屏收尾检查

- 终端没有显示本机用户名、密钥、真实联系方式或未脱敏文件。
- `ready_for_local_demo` 为 true，但没有把 warning 说成通过。
- 数据准确称为“公开合成冻结内部回归”，没有称为独立盲测。
- Windows/V11数据分开，均标明HashEmbedding及实际P95范围。
- 测试数与现场终端、摘要、字幕及PPT一致。
- 最终视频已从头到尾人工观看，画面、声音、字幕、路径和隐私均无误。
- 成片不超过7分钟，计划6分30秒。
- 没有宣称平台审核、报名表、邮件回执、真实案例或赛事V11部署认可已经完成。
