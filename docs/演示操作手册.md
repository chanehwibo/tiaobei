    "knowledge_search_latency_ms": 1.5,
    "conflict_accuracy": 1.0,
    "forget_accuracy": 1.0

## 5. 录屏旁白稿

### 开场

> 大家好，现在演示的是 OS Agent 记忆优化及高效应用研究项目。这个原型面向麒麟操作系统 OS Agent 的长期记忆能力，重点展示多源数据接入、偏好记忆、知识记忆、知识检索、冲突处理、自然语言遗忘、评测报告和本地持久化。

### 环境说明

> 当前演示在 Windows PowerShell 中进行。项目目前是纯 Python 标准库原型，不需要安装额外依赖。首先确认 Python 版本，然后进入项目根目录，并设置 `PYTHONPATH` 指向 `src`。

### 功能演示

> 现在运行样例 demo。系统会读取 `data/samples/events.jsonl` 中的多源事件，对内容进行清洗和脱敏，然后抽取偏好记忆和知识记忆。这里可以看到系统抽取出 3 条活跃偏好、5 条活跃知识，并识别到 1 条知识冲突。

> 接着看偏好结果，系统识别出用户偏好表格输出、敏感信息脱敏，以及办公报表场景下偏好使用 `spreadsheet_parser` 工具。这说明偏好记忆具备版本化和证据追踪的基础能力。

> 再看知识检索部分，输入“报销流程模板”后，系统返回报销流程规则、结构化总结和邮件模板等相关知识。随后执行“删除报销模板相关记忆”，可以看到系统识别出关键词并软删除 1 条知识记忆。

### 评测演示

> 现在运行标注评测。评测集位于 `data/eval/office_memory_eval.json`，覆盖 11 条多源事件、4 条偏好标注、5 条检索查询、4 条冲突用例和 3 条遗忘用例。

> 这里终端显示五项核心指标：偏好提取准确率、知识检索召回率、检索延迟、冲突处理准确率和遗忘准确率。当前五项 targets 全部为 true，说明在这版标注集上全部达标。

## 9. 常见故障速查

| 问题现象 | 快速判断 | 处理命令或动作 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'os_agent_memory'` | Python 找不到项目包 | 执行 `cd "C:\Users\CanhuiBao\Desktop\挑战杯 揭榜挂帅\os-agent-memory-optimizer"`，再执行 `$env:PYTHONPATH="$PWD\src"` |
| `FileNotFoundError` | 当前目录不对或路径没加引号 | 回到项目根目录，复制手册里的完整命令 |
| PowerShell 不让运行脚本 | 执行策略限制 | 使用 `powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1"` |
| `Ran 0 tests` | unittest 没发现测试目录 | 使用 `python -m unittest discover -s tests` |
| 评测报告不存在 | 没运行 `evaluate --output` | 执行步骤 5 的完整命令 |
| SQLite 文件不存在 | 没运行 `build-store` | 执行步骤 7 的完整命令 |
| SQLite 文件被占用 | 数据库查看器或编辑器打开了文件 | 关闭占用工具后重跑 `build-store` |
| 输出乱码 | 控制台编码问题 | 执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 后重跑 |
| 检索延迟偶尔偏高 | 机器负载高或首次运行抖动 | 关闭其他程序后重跑评测；看 `targets.knowledge_search_latency_ms` 是否为 `true` |
