## 1. 结论摘要

当前版本在 Windows 开发机完成 54 项自动化测试、120 条分区合成数据评测和最高 10,000 条知识规模测试。仓库内测试全部通过；v2 test 分区全部预设阈值通过；10,000 条时冷查询 62.541ms、热查询 p99 73.445ms。

这些结果证明当前源码、HashEmbedding 回退方案和 SQLite v2 在本开发机可复现，不证明真实银河麒麟 embedding SDK 达标。兼容性报告的“真实银河麒麟环境”“真实 SDK”“赛题指定环境整体就绪”均为否或未验证。

## 4. 测试数据与来源

### 4.1 v1 小型回归集

`data/eval/office_memory_eval.json` 含 11 条事件、9 条偏好标签、6 条检索查询、4 条冲突用例和 3 条遗忘用例，用于保持早期功能兼容。

### 4.2 v2 扩展集

`data/eval/office_memory_eval_v2.json` 由 `scripts/generate_eval_v2.py` 确定性生成，共 120 条事件，train/dev/test 各 40 条。覆盖报销、会议、公文、文件归档、终端安全、客户邮件六类场景和通用噪声，并包含失败工具、提示注入、同义表达、无答案、冲突、隐私和跨用户反例。

全部数据均为合成数据，test 标签公开，只能作为冻结回归分区，不能宣称第三方独立盲测。

## 5. 指标口径

- 偏好：微平均 Precision、Recall、F1；多报键值计假阳性。
- 检索：Precision@K、Recall@K、MRR、nDCG@K；无答案只有正确返回空集才通过。
- 冲突：识别 Precision、Recall、F1 和包含解决结果的用例准确率。
- 遗忘：Precision、Recall、F1、用例准确率和误删率；任何授权集合外删除均处罚。
- 性能：首次查询为冷查询，后续同进程查询报告 p50/p95/p99 和 QPS；500ms 判定取冷查询与热 p99 的较大值。
- 资源：tracemalloc 记录 Python 峰值分配，SQLite 完整保存后记录磁盘体积。

## 10. 已发现并修复的关键问题

1. 复合偏好只保留单值：改为多维键。
2. 失败工具被学习为首选：失败/取消结果排除并降权。
3. 输入顺序覆盖事件时间：以有效时间和权重决策。
4. 未决冲突参与回答：默认隔离。
5. 矛盾文本直接拼接：改为证据合并和胜出决策。
6. 查询重复计算文档向量：改为入库缓存、候选重排。
7. 多租户缺少作用域：歧义时拒绝，并增加越权测试。
8. 遗忘直接执行：改为预览、确认、过期令牌和审计。
9. 误删指标只检查少量保留标题：改为授权外任何删除均处罚。
10. 冲突淘汰被误算为本次遗忘：按本次 affected IDs 计分。
