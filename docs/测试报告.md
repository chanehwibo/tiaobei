## 证据层级

| 层级 | 可支持结论 | 不能支持的结论 |
| --- | --- | --- |
| 冻结五项回归 | 指定HashEmbedding和公开数据上的指标及安全门槛 | 原生SDK、独立盲测或新领域泛化 |
| 复杂干扰回归 | 近似实体、时效、跨域、多证据与长文本下的分层质量和延迟 | 授权真实业务收益 |
| 本地消融及配对对比 | 同数据、配置和环境下的实现差异 | 其他论文端到端系统的胜负 |
| SDK真实单探针 | 旧ABI曾执行一次768维向量调用 | 原生P95<=500ms |
| V11历史报告 | 对应历史源码的实际安装与测试 | 当前源码服务部署已通过 |
| 自动测试与允许列表预检 | 代码回归、证据一致性和计划布局完整性 | 已生成新ZIP、解包通过、赛事评分或人工审核 |
