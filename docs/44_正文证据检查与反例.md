# 正文证据检查与反例

状态：**已完成初版，待赛事验收**。本节记录工程试验与失败边界，
不把功能实现或单元测试通过写成复杂检索质量达标。

## 1. 目的与决策

近实体/版本过滤可以排除不适用材料，但相同实体的文档不一定支持所问关系。
新增`content_coverage_v1`作为**默认关闭的实验对照**：

- 原有候选、排序、top_k=3和相似度阈值0.265不变。
- 只读已授权结果的标题、正文；标签、来源ID及隐藏文档不参与证据覆盖。
- 显式约束和结果共有标题折扣，问句结构词不作为事实；中文相邻字对、英文完整词匹配。
- 多条返回文档可共同覆盖问句，覆盖不足预先固定的0.5时拒答。
- 不缓存原始问句/正文，不增加遗忘后残留文本副本；不改写原始结果分数。

**决策：默认仍为`similarity`，不推荐将实验策略直接用作业务拒答器。**
它减少部分近主题误返回，却会误拒长背景和同义问法；同词汇的错误关系仍可能通过。
这不是语义蕴含模型、自动条件推理或置信概率，不包装成技术首创。

## 2. 开发与公开对照

开发集`data/dev/evidence_coverage_v1.json`包括计量台、工单附件、钥匙借还、
时钟源变更和英文交接，共10条文档、20个不同请求，正例/无答案各10个。
先固定0.5多数覆盖规则并检查开发集，再运行原有冻结复杂集；没有扫描其阈值。

| 初次对照 | 默认召回@3 | 实验召回@3 | 默认无答案正确 | 实验无答案正确 |
| --- | --- | --- | --- | --- |
| 开发集20请求 | 100% | 100% | 3/10 | 10/10 |
| 原复杂集120请求，1000条/75%相似填充 | 94.44% | 81.94% | 1/24 | 22/24 |
| 约束集48请求，显式约束开启，1000条/75%相似填充 | 95.83% | 60.42% | 8/12 | 12/12 |

以上复杂集实验策略均**未达到召回与无答案同时>=85%的内部质量门槛**。
初次运行只用于功能诊断，并行执行时的时延不作为正式性能对照。
原始输出位于`artifacts/verification/feedback/implementation-20260910/`的
`development_initial.json`、`complex_policy_initial.json`及`constraints_policy_initial.json`。
这些报告绑定各自生成时源码，最终同源复测另存新文件，不覆盖历史输出。

## 3. 追加开发反例

公开对照暴露副作用后，新建`data/dev/evidence_coverage_challenge_v1.json`，
复用已冻结的10条开发文档，增加10个不同请求：6个长背景/同义正例、4个无证据问题。
它是**看到失败后补充的开发反例**，不是事先隐藏的泛化测试。

默认召回为5/6，实验策略为0/6；两种策略无答案均为2/4。
对应`development_challenge_initial.json`完整保留8条实验失败记录。
该结果解释了为何不能依据前20条开发用例的100%表现启用策略。
后续需要更丰富的授权脱敏样本、语义证据校验和独立标注复核，
不能靠不断提高相似度阈值、删掉难例或复制同一模板凑样本。

## 4. 复现和计分边界

```bash
PYTHONHASHSEED=0 python -B -X utf8 -S scripts/evaluate_evidence_development.py --output new-development.json
PYTHONHASHSEED=0 python -B -X utf8 -S scripts/evaluate_evidence_development.py --challenge --output new-challenge.json
PYTHONHASHSEED=0 python -B -X utf8 -S scripts/evaluate_complex_retrieval.py --evidence-policy compare --output new-comparison.json
PYTHONHASHSEED=0 python -B -X utf8 -S scripts/evaluate_complex_retrieval.py --suite complex_constraints_v1 --constraints compare --evidence-policy compare --output new-constraints.json
```

Windows PowerShell先设置`$env:PYTHONHASHSEED="0"`，再执行对应Python命令。
输出拒绝覆盖；每个请求保留结果、分数、错误与耗时，拒答错误不从分母移除。
三次重复只能衡量运行波动，不能变成三倍独立样本。
默认/实验策略、显式约束开/关分别报告，不能只挑高分配置或合并为一个成绩。
复杂压力集共168个不同请求，与30个开发请求的用途不同，不合并计分。
这些均是公开合成数据，不冒充真实现场日志、第三方盲测、原生SDK或赛事认可结果。
