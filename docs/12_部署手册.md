# 部署与运行手册

## 1. 支持范围

- Python：3.10 及以上。
- 核心依赖：仅 Python 标准库。
- 开发验证：Windows 10 / AMD64 / CPython 3.14.3。
- 目标系统：银河麒麟桌面操作系统；尚需在发榜单位指定版本和架构实测。
- Web：本地演示服务，默认仅监听 `127.0.0.1`。

## 2. 获取源码

```powershell
git clone https://github.com/chanehwibo/tiaobei.git
cd tiaobei
git status --short
```

本文档假设当前目录是仓库根目录，不依赖作者电脑上的绝对路径。

## 3. Windows 部署

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python -m os_agent_memory.cli doctor --workspace . --input ".\data\samples\events.jsonl" --suite ".\data\eval\office_memory_eval_v2.json"
```

如执行策略阻止激活，可在当前进程运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## 4. 银河麒麟部署

以下命令需在真实目标机执行，并以发榜单位文档为准：

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -e .
python3 -m os_agent_memory.cli compat-check \
  --workspace . \
  --output-json artifacts/runtime/compatibility_kylin.json \
  --output-md artifacts/runtime/compatibility_kylin.md
```

若 FTS5 不可用，不应静默继续并宣称完整兼容；应按银河麒麟软件源安装带 FTS5 的 Python/SQLite，或为检索层增加明确降级实现后重新测试。

## 5. 接入真实 embedding SDK

先按发榜单位文档安装 SDK，再自检：

```bash
python3 -m os_agent_memory.cli kylin-sdk-check \
  --module "实际模块名" \
  --factory "实际工厂名" \
  --method "实际向量方法" \
  --response-path "实际.向量.路径" \
  --factory-kwargs '{"model":"实际模型名"}' \
  --output artifacts/runtime/kylin_sdk_check.json
```

访问令牌只通过 SDK 官方建议的环境变量或权限受控配置传入；不得写入命令历史、JSON 报告、源码或 Git。自检为 `ready` 只证明单次接口契约通过，仍需复跑功能和性能。

## 6. 命令行运行

未执行可编辑安装时，可临时设置模块路径：

Windows：

```powershell
$env:PYTHONPATH="$PWD\src"
```

银河麒麟：

```bash
export PYTHONPATH="$PWD/src"
```

常用命令：

```text
python -m os_agent_memory.cli demo --input data/samples/events.jsonl
python -m os_agent_memory.cli build-store --input data/samples/events.jsonl --output artifacts/runtime/memory.sqlite
python -m os_agent_memory.cli serve --input data/samples/events.jsonl --database artifacts/runtime/memory.sqlite
python -m os_agent_memory.cli evaluate --suite data/eval/office_memory_eval_v2.json --split test --top-k 3 --summary-only
```

## 7. Web 演示

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1"
```

浏览器访问 `http://127.0.0.1:8765`。端口占用时使用 `-Port 8766`。如只做命令链验收，使用 `-NoServer`。

当前仅用于可信本机调用。已实现作用域一致性、跨源写入拒绝、单进程事务与失败回滚，但没有登录认证、TLS 和生产限流，也不支持多进程共享写入同一 SQLite。

第二轮可对 serve、build-store、evaluate、benchmark 加 --embedding-config config/embedding.hash.json。真实 SDK 的配置结构见 config/embedding.kylin.example.json；填写真实模块、版本和维度后仍须重新验收。

## 8. 数据目录与备份

- `data/samples/`：可公开的合成样例。
- `data/eval/`：合成评测及生成器输出。
- `artifacts/verification/`：仓库内固定验证证据。
- `artifacts/runtime/`：运行时报告和 SQLite，默认不进入 Git。
- `case_studies/private/`：签署材料和原始案例，默认不进入 Git。

SQLite 备份前应停止写入或使用 SQLite 官方在线备份机制。硬删除只处理当前数据库，不自动清理外部备份、日志或导出副本；生产部署必须补充保留与销毁策略。

## 9. 故障排查

| 现象 | 检查 | 处理 |
| --- | --- | --- |
| 找不到模块 | `python -c "import os_agent_memory"` | 激活虚拟环境并 `pip install -e .`，或设置 PYTHONPATH |
| 端口占用 | 运行 `doctor --port <端口>` | 换端口或停止占用进程 |
| SQLite 锁定 | 检查是否有数据库查看器 | 停止并发写，关闭查看器后重试 |
| SDK unavailable | 查看 `error_type` | 核对安装、模块名、架构和动态库路径 |
| SDK incompatible | 查看方法/返回路径 | 按真实响应调整 method/response-path |
| 检索空结果 | 检查作用域、scene、min_score | 不要直接取消作用域；先定位过滤条件 |
| 遗忘计划过期 | 查看 expires_at | 重新预览并由用户再次确认 |

## 10. 卸载

可编辑安装可用 `python -m pip uninstall os-agent-memory-optimizer` 移除。删除虚拟环境和运行时数据库前先确认路径、备份与保留要求；不得用针对用户目录或仓库根的递归删除命令。
