# 源码导出与交付候选

在工程根目录执行：

```powershell
python -X utf8 -S scripts/export_source.py --output artifacts/runtime/source-review.zip
```

工具导出执行时的 Git HEAD，并在 ZIP 内写入 `SOURCE_MANIFEST.json`，记录提交号和每个文件的 SHA256。
它不会包含工作区未提交的材料改动、Git 历史、虚拟环境和运行缓存，也不会修改工作区。
包含已跟踪的历史证据和材料，仍须按各自标注的源码版本解读；这不是新的赛事验收证明。
导出后打印整个 ZIP 的 SHA256。目标存在时拒绝覆盖；已跟踪的私有目录、密钥、运行库或符号链接会阻止导出。
旧 ZIP 原样保留，不应直接压缩整个工作文件夹作为新版源码。

2026-10-12检查发现旧视频时长618.767秒，超过本地官方提交规则的600秒上限。
另存的时长调整候选采用以下变换，保留完整时间范围和音轨，移除容器元数据：

```text
ffmpeg -n -i input.mp4 -map 0:v:0 -map 0:a:0 -vf setpts=PTS/1.05 -af atempo=1.05
       -c:v libx264 -preset fast -crf 20 -c:a aac -b:a 160k -map_metadata -1 -movflags +faststart output.mp4
```

输出约589.3秒，音频保持音高；这是时长调整，视频原有的算法、指标和界面仍对应录制时版本。
候选文件的时长、音视频解码、大小另行核验；正式使用前仍需按当前代码重新确认讲解、可读性及画面匿名情况。
本次生成的候选和原始视频都没有上传赛事平台。
