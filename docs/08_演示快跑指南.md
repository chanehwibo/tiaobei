# 08 演示快跑指南

状态：**已完成初版，待赛事验收**。当前口径见 `docs/37_出题方反馈落实.md`。历史Windows/V11回归只对应当时源码，不代表当前版本通过独立盲测或官方验收。视频上限7分钟，建议6分30秒。

## 一条命令

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1"
```

脚本依次执行环境预检、样例闭环、v2历史诊断、10,000条逐请求五项硬门槛、SQLite v2构建、全部自动化测试，随后在 `http://127.0.0.1:8765` 启动仪表盘。按 `Ctrl+C` 停止。v2旧标签有未达项，保留原始输出，不将它当作当前发布门槛。

持续集成或只验收命令链时，不启动服务器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1" -NoServer
```

## 失败自检

预检会把问题分为两类：

- 阻断项：Python 版本、样例/评测文件、目录写权限、SQLite FTS5、端口占用；任一失败即停止。
- 外部警告：本机环境/SDK状态只对应当前进程；V11客户机证据另见 `docs/31_麒麟V11客户机实测.md`，旧ABI单探针不等于原生完整集成。

端口被占用时可运行 `-Port 8766`。Python 命令不是 `python` 时可运行 `-PythonCommand py`。已取得真实 SDK 时可传 `-SdkModule "实际模块名"` 进行基础导入和默认接口自检。

## 演示顺序

1. 展示预检 JSON，说明本机能力和外部待验事项。
2. 展示样例数据脱敏、偏好、检索、冲突与遗忘结果。
3. 展示 `artifacts/runtime/latest_requests.json` 的五项数值、分母、逐请求结果和附加安全门槛。
4. 展示全部测试 `OK`。
5. 打开仪表盘，依次演示偏好、查询、冲突和两阶段遗忘。

运行产物写入 `artifacts/runtime/`，该目录中的 SQLite 和临时评测报告不作为最终固定证据。
