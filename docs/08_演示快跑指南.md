# 08 演示快跑指南

第四轮口径：偏好≥85%、召回≥85%、冲突≥88%、检索P95≤500ms、敏感F1≥90%，每项至少50独立请求，强制银河麒麟V11。现场以 docs/28_第四轮验收报告.md 和 round4/evidence_summary.json 为准；下文旧测试数及性能数属于历史示例。真实SDK、行动框架自检和正式Agent评测须分别表述。

## 一条命令

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1"
```

脚本依次执行环境预检、样例闭环、v2 test 分区评测、SQLite v2 构建、全部自动化测试，随后在 `http://127.0.0.1:8765` 启动仪表盘。按 `Ctrl+C` 停止。

持续集成或只验收命令链时，不启动服务器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\run_demo.ps1" -NoServer
```

## 失败自检

预检会把问题分为两类：

- 阻断项：Python 版本、样例/评测文件、目录写权限、SQLite FTS5、端口占用；任一失败即停止。
- 外部警告：真实银河麒麟环境和真实 Kylin embedding SDK 未验证；不阻断开发机演示，但禁止据此宣称赛题指定环境达标。

端口被占用时可运行 `-Port 8766`。Python 命令不是 `python` 时可运行 `-PythonCommand py`。已取得真实 SDK 时可传 `-SdkModule "实际模块名"` 进行基础导入和默认接口自检。

## 演示顺序

1. 展示预检 JSON，说明本机能力和外部未完成项。
2. 展示样例数据脱敏、偏好、检索、冲突与遗忘结果。
3. 展示 v2 test 分区的 Precision/Recall/F1、MRR、nDCG 和误删率。
4. 展示全部测试 `OK`。
5. 打开仪表盘，依次演示偏好、查询、冲突和两阶段遗忘。

运行产物写入 `artifacts/runtime/`，该目录中的 SQLite 和临时评测报告不作为最终固定证据。
