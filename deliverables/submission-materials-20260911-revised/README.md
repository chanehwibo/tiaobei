## 保留的结论边界

冻结服务P95为48.145ms，但仅对应Windows/HashEmbedding。
真实SDK仍是**待复测风险项**：13,390.615ms为单探针，不是原生P95。
复杂回归修复了完整召回和拒答，仍有31.71%/23.08%的干扰返回；
原复杂集证据检查增加了时延，不声称普遍加速。

当前数据是开发可见合成回归，不是独立盲测、真实Agent回答正确率或真实用户收益。
