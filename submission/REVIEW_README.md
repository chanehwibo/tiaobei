未来授权封包后才使用`03_源代码与说明/project`作为解包工作目录：

```powershell
$env:PYTHONHASHSEED = '0'
$env:PYTHONPATH = "$PWD\src"
python -B -X utf8 -S -m unittest discover -s tests -v
python -B -X utf8 -S scripts/check_source.py
python -B -X utf8 -S scripts/evaluate_requests.py --size 10000 --require-frozen --output artifacts/runtime/review-focused-requests-new.json
```
