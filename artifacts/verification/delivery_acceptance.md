
`-S` 禁用 Python 的 site 初始化，验证核心测试不依赖本机用户级安装的第三方包。该运行输出 `Ran 65 tests in 5.848s`、`OK`。解压目录内材料完整性检查通过，隐私扫描检查 72 个文本文件，异常 0 项。

- 源码区保留 `docs/`、`submission/`、固定证据和可编辑材料的相对路径，解压后的工程可再次打包。
