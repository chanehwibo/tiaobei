# 真实应用案例工作区

本目录只提交空白模板和匿名化规则，不提交参与者姓名、联系方式、签名、原始办公文件或可反向识别的信息。

执行顺序：

1. 在测试前向参与者说明目的、流程、数据类型、风险和退出方式，并取得书面同意。
2. 将签署文件与原始数据放在仓库外，或本仓库已忽略的 `case_studies/private/`。
3. 为参与者分配随机编号；使用模板记录任务级结果，不记录姓名、部门全称或客户名称。
4. 由另一名成员按匿名化清单复核。
5. 只将不含个人信息的聚合结果写入正式报告；必要时记录外部证据文件的 SHA-256，而不上传证据本体。

禁止事项：不得虚构参与者、反馈、耗时或业务收益；未同意的材料不得采集；参与者撤回后应删除对应原始数据和可关联记录。
